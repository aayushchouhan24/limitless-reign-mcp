# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via email rather than creating a public issue.

Email: [Create a private security advisory on GitHub]

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

We will respond within 48 hours and work with you to address the issue.
